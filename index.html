Mnemosxema

Korxona DCS ekrani geometriyasi asosida. Rezervuardagi suyuqlik sathi DCS o‘lchagichi ko‘rsatkichi bo‘yicha to‘lib-kamayadi; yashil — ochiq klapan yoki ishlayotgan nasos, uch yo‘lli klapanda yashil tomon — minimal oqim yo‘nalishi.

Gaz yostig‘i (PCV), PVSV 54 / −1,6 kPag va minimal oqim shaybasi (FO) DCS ekranida ko‘rsatilmaydi, lekin modelda hisobga olingan.

Mnemosxemani to‘liq ko‘rish uchun yonga suring.

Sichqoncha bilan aylantiring, g‘ildirak bilan yaqinlashtiring, uskunani bosib ma’lumot ko‘ring. Pastdagi o‘ynatish tugmasi bilan jarayonni yurgizing.

    O‘z ma’lumotingiz

    Matematik model

    Simulyator va MATLAB moduli bir xil tenglamalarga asoslangan. Vaqt — daqiqa, oqim — m³/soat, sath — %. Quyidagi ifodalar maqoladagi (1)–(6) formulalarga mos.

    1. Rezervuar dinamikasi (massa balansi)

    dLᵢ/dt = 100·( Qkir·sᵢ·(1−HHᵢ) − n·u·Qn·cᵢ − Qm·cᵢ + Qm·mᵢ − Qsiz ) / (60·V), 0 ≤ Lᵢ ≤ 100

    Qkir — ishlab chiqarish oqimi; sᵢ, cᵢ — kirish va chiqish klapanlari ulushi; n — ishlayotgan nasoslar; u — unumdorlik nisbati; Qn — nasos unumi; Qm — minimal oqim; mᵢ — uch yo‘lli klapan minimal oqimni i-rezervuarga yo‘naltirsa 1; HHᵢ — SIS LAHH relesi.

    2. SIS blokirovkasi (P&ID)

    LL = OR(Sₐ ≤ LLL, Sb ≤ LLL) → nasoslar to‘xtaydi HH = OR(Sₐ ≥ LHH, Sb ≥ LHH) → kirish klapani yopiladi (signal yo‘qolsa — fail-safe: kanal «trip» ovozini beradi)

    3. O‘lchov modeli

    LDCS = L + bD + ε, Sₐ = L + bₐ + ε, Sb = L + bb + ε, ε ~ N(0, (k·σ)²)

    4. AI belgilari

    z = (v − vkut) / σ, σ = √( (0,03·k)² + (0,15·n·qn)² ) z₆₀ — nasos ishlamagan 60 daqiqalik oynadagi o‘rtacha qoldiq x₃ = max( IF-bal, |z|, |z_bosim|, |z₆₀| ) (bal — [0;1] ga keltirilgan)

    Isolation Forest: 100 daraxt, 256 tanlanma, 40 ta normal ssenariyda o‘qitiladi; s(x) = 2−E[h(x)]/c(n), bal o‘qitish ballari medianasi → 0, maksimumi → 1 bo‘yicha me’yorlanadi. Isolation Forest faqat x₃ ga kiradi; sabab tashxisi fizik qoidalar asosida bajariladi. Sizish va aylanma oqim tashxisi chegarasi zT normal ssenariylardagi |z₆₀| maksimumidan o‘rganiladi: zT = max(2,0; 3·max|z₆₀|), lekin 6,8 dan oshmaydi.

    5. Dinamik xavf indeksi

    x₁ = sat( (2·LA − LT − L) / (2·(LA − LT)) , 0, 1 ) τ = (L − LT) / (−v), x₂ = sat( 1 − τ / Tu, 0, 1 ), Tu = 60 min x₄ = sat( (Δ − 1,5) / 4,5, 0, 1 ), Δ = max(|LDCS − S̄|, |Sₐ − Sb|) R = maxj( w₁·x₁ⱼ + w₂·x₂ⱼ ) + w₃·x₃ + w₄·x₄, R ≥ R* (ketma-ket 3 o‘lchov) ⇒ ogohlantirish

    Vaznlar: w₁ = 0,20; w₂ = 0,50; w₃ = 0,15; w₄ = 0,15. R* = 0,45.

    6. Baholash ko‘rsatkichlari

    lead time = thodisa − togohlantirish (ogohlantirish nosozlikdan 10 min oldingi paytdan hisobga olinadi), yetarli ulush = P( lead ≥ Tjavob ), Tjavob = 10 min tashxis aniqligi = to‘g‘ri sabab va rezervuar / jami ssenariy

    MATLAB moduli

    Shu tenglamalarning mustaqil dasturiy amalga oshirilishi Matematik_modul_MATLAB papkasida (paketda): ishga_tushirish.m — to‘liq hisob, bitta_ssenariy.m — bitta holat va grafik, ommaviy_sinov.m — 5- va 6-jadvallar, sezgirlik_tahlili.m — chegara tanlash, simulink_model_yaratish.m — Simulink modeli. MATLAB modulida shu simulyatordagi tasodifiy sonlar generatori (Mulberry32, js_rand.m) ishlatiladi, shuning uchun bir xil urug‘larda ssenariylar va natijalar bir xil chiqadi.
